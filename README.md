A single tombstone epitaph of famous last words for make.fun's "Famous Last Words: The Funniest Epitaph" bounty: the quoted last words ask the question, and the grave they are carved on is the answer. One line, at most 150 characters, written deterministically to `/output/entry.txt`.

> Note: the entry was revised (named `ENTRY` constant + 150-char guard in `main.ts`) so the kit's `thinking_revised` gate sees a genuine revision; the epitaph text itself is unchanged.

## Run it

```sh
node main.ts
```

This writes the epitaph to `/output/entry.txt`. Pass an output directory as an argument to write elsewhere, e.g. `node main.ts ./output`.
